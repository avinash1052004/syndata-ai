# Syndata AI - Intelligent Data Analysis Platform

🚀 **Transform Data into Intelligent Decisions**

Syndata AI is an advanced data intelligence platform that combines automated machine learning, interactive 3D visualization, and natural language processing to provide comprehensive data analysis.

## Features

- 🤖 **Automated Machine Learning** - AutoML for classification and regression
- 📊 **Interactive 3D Visualizations** - Stunning 3D plots and charts
- 🔍 **Advanced Correlation Analysis** - Discover relationships in your data
- 📈 **Time Series Forecasting** - Predictive analytics for time-based data
- 👥 **Customer Segmentation** - RFM analysis and clustering
- 💬 **Natural Language Chat** - Chat with your data using AI
- 📄 **PDF Report Generation** - Comprehensive analysis reports

## Quick Start

1. **Upload your dataset** (CSV, Excel, or JSON)
2. **Run comprehensive analysis** with one click
3. **Explore insights** through interactive visualizations
4. **Chat with your data** using natural language
5. **Generate PDF reports** for professional presentations

## Deployment

### Local Development

pip install -r requirements.txt
